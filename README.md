# 🎮 Recomendador de Videojuegos

## 1. Nombre del proyecto

**Recomendador de Videojuegos**

---

## 2. Descripción

Este proyecto consiste en una página web que recomienda videojuegos mediante tarjetas visuales. Cada tarjeta muestra una imagen del videojuego, su nombre, año de lanzamiento, calificación y un enlace a un tráiler en YouTube.

---

## 3. Tecnologías utilizadas

- HTML
- CSS
- Bootstrap
- JavaScript
- Git
- GitHub
- Inteligencia Artificial: Microsoft Copilot

---

## 4. Proceso con IA

### Prompt 1

> "Genera una tarjeta de Bootstrap para mostrar un videojuego con imagen, título, año y botón de YouTube."

**Resultado:**  
La IA generó la estructura básica de la tarjeta, incluyendo la imagen, el título, el año de lanzamiento y un botón con enlace a YouTube.

---
